Mini Project 1 - Job Snippet

Step 1:
Ensure the requirements are installed using 
pip install -r requirements.txt

Step 2:
Ensure the input data [ golden data and job snippet josn's are in data/]
Create .env file with the API KEY AND BASE with the exact variable names
OPENAI_API_KEY
OPENAI_BASE_URL

Step 3:
Copy the script into src/ 
Run the script "src/mp1_prompt_lab.py" using 
python -m "src/mp1_prompt_lab.py"

Step 4:
Validate the results that are written inside data folder

P.s:
To view the comparision table inside src/comparision_table.md and src/mp1_writeup.md use Shift + CMD + V, which displays the md file in pretty print format.
